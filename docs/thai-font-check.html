เทียบฟอนต์ไทย — ของที่ใช้อยู่ vs Sarabun

ทั้งสี่ตัวข้างล่าง มีหัวหมด — ต่างกันที่ขนาดหัวและความกว้าง ระบบตอนนี้ใช้ IBM Plex Sans Thai ซึ่งหัวเล็กและทรงเรขาคณิต ส่วน Sarabun หัวใหญ่กว่าและช่องในตัวอักษรเปิดกว่า

ทำไม mockup ถึงดูไม่เหมือนแอป

mockup รุ่นก่อนประกาศ --font-sans: "IBM Plex Sans Thai", "Leelawadee UI", "Noto Sans Thai", Sarabun, Tahoma… แต่ไม่ได้โหลดฟอนต์ (ไม่มี @font-face ไม่มีลิงก์) — และเครื่อง Mac เครื่องนี้ ไม่มี IBM Plex Sans Thai ติดตั้ง ส่วน Leelawadee UI กับ Noto Sans Thai ก็ไม่มี ⇒ ตกไปตัวถัดไปในลิสต์ที่มีจริงคือ Sarabun

ตรวจแล้วด้วย system_profiler SPFontsDataType — ในตระกูลที่เกี่ยวข้อง เครื่องนี้มีแค่ Family: Sarabun · ส่วนแอปจริงไม่พึ่งฟอนต์ในเครื่องเลย เพราะ next/font/google โฮสต์ไฟล์เอง

ถ้าจะเปลี่ยนทั้งระบบ ต้องแตะอะไรบ้าง

#ไฟล์ต้องทำอะไร
1src/app/layout.js สลับ IBM_Plex_Sans_Thai → Sarabun จาก next/font/google · Sarabun มี 400/500/600/700 ครบ (ไม่ต้องแตะโทเคน --fw-*)
2src/app/globals.css แก้ชื่อสำรองใน --font-sans · --font-mono/--font-numeric ชี้ตัวเดียวกันอยู่แล้ว
3src/lib/sales/quotationDocumentFonts.js ก้อนใหญ่สุด — ไฟล์ 118KB ที่ฝัง woff2 เป็น base64 8 บล็อก (400/500/600/700 × thai/latin) ต้อง regenerate ใหม่จาก Sarabun ไม่งั้นใบพิมพ์/ฉบับตรึงยังเป็นฟอนต์เดิม
4src/lib/printTheme.js + printTheme.test.mjs แก้ PRINT_FONT_STACK · เทสต์ assert หาคำว่า IBM Plex Sans Thai อยู่ ต้องแก้คู่กัน
5webapp/UI_DESIGN_SYSTEM.md ย่อหน้า “ตัวเลขตรงคอลัมน์อยู่แล้วโดยกำเนิด เพราะ 0-9 ของ IBM Plex Sans Thai กว้าง 600/1000 em” ต้องแก้เลขเป็น 550/1000 em ของ Sarabun (วัดแล้วยังเท่ากันทุกหลัก)
6วัดซ้ำ --ui-badge-w-* ทุกตัวถูกวัดจากฟอนต์เดิม · ต้องวัดใหม่ตาม §“ความกว้างต้องวัดจากของจริง” แล้วรูดค่าลงถ้าแคบลงจริง
7CI npm run audit:ui (font-family นอกโทเคน = 0) · fontWeightScale.test.mjs ผูก layout.js กับโทเคนน้ำหนักไว้ · npm test · npm run build

🪤 ไม่มีสคริปต์ generate ฟอนต์เอกสารในรีโป — หัวไฟล์ quotationDocumentFonts.js เขียนว่า “อย่าแก้มือ: รันสคริปต์ generate ใหม่” แต่ค้นทั้งรีโปแล้วไม่มีสคริปต์นั้น ⇒ ข้อ 3 ต้องเขียนสคริปต์ขึ้นมาก่อน (และคอมมิตไปด้วย ไม่งั้นรอบหน้าเจอปัญหาเดิม)

⚠️ ฉบับตรึง (issued snapshot) ที่ออกไปแล้วไม่เปลี่ยนตาม — เอกสารที่อนุมัติแล้วฝัง CSS ของฟอนต์ไว้ใน snapshot ตอนตรึง (ADR 0011) เอกสารเก่าจะยังเป็นฟอนต์เดิมตลอดไป ซึ่ง ถูกต้องแล้ว — ฉบับตรึงต้องเล่นซ้ำได้เหมือนวันที่เซ็น ห้ามแก้ย้อนหลัง
