เทียบกับหน้าดีลทีละชิ้น — ขอบเขต Segmented ✓ · MetricStrip ✓ · แบนเนอร์เตือน+ปุ่มพาไปตัวกรอง ✓ · การ์ด+badge จำนวน ✓ · ค้น → ตัวกรอง → จัดกลุ่ม → ย่อ/ขยาย → เรียง+ทิศทาง ✓ · หัวกลุ่มย่อ/ขยายได้ ✓

ได้อะไรไม่ต้องออกแบบอะไรใหม่เลย — ทุกชิ้นมีอยู่แล้วและผ่านการใช้จริง · คนที่ใช้หน้าดีลเป็นอยู่แล้วใช้หน้านี้เป็นทันที · ได้ "จัดกลุ่ม" ที่หน้าคำร้องไม่เคยมี (ตามฝ่าย · ลูกค้า · ชนิด · ผู้รับเรื่อง) พร้อมย่อ/ขยายรายกลุ่ม · ได้เรียงลำดับที่เลือกเองได้
ต้องตัดสินเพิ่ม 1 ข้อหน้าดีลเอา สถานะ ใส่ในแผงตัวกรอง แต่หน้างาน PM จงใจไม่เอาเข้าเพราะ "เป็น drill-down" — คิวคำร้องเข้าข่ายหลัง (สถานะ = เหตุผลที่เปิดหน้ามา) ⇒ ข้อเสนอ: MetricStrip 4 ตัวกดแล้วกรองในที่ ทำหน้าที่แทนแท็บสถานะ ส่วนแผงเก็บมิติที่เหลือ

ผมแนะนำ: จ + ข

สองแบบนี้แก้คนละปัญหาและไม่ชนกัน — ทำพร้อมกันได้ในรอบเดียว

จ ลอกโครงหน้ารายการดีล — เป็นมาตรฐานที่ระบบประกาศไว้เองแล้ว · ได้ตัวกรองจัดกลุ่ม + จัดกลุ่มแถว + เรียงลำดับ ครบในรอบเดียวโดยไม่ต้องออกแบบใหม่ · MetricStrip กดกรองแทนแท็บสถานะ
งแก้ สามชั้นกรอง ⇒ ชิปสถานะแถวเดียว (เห็นตลอด) + แผงตัวกรองจัดกลุ่มสำหรับมิติที่เหลือ · เป็น ก ที่ใช้คอนโทรลของบ้านแทนการคิดใหม่ และมีที่ให้มิติที่ยังไม่มี (ลูกค้า · ผู้รับเรื่อง) โดยแถวบนไม่ยาวขึ้น
กเวอร์ชันไม่มีแผง — เลือกอันนี้ถ้าอยากให้ทุกตัวกรองเห็นหมดตลอดเวลา และยอมให้แถวบนตกบรรทัดบนจอแคบ
ขแก้ ตารางสามชุด ⇒ เหลือชุดเดียว เปิด/ปิดคอลัมน์ตามบริบทผ่าน props
