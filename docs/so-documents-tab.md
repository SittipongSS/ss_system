# แท็บ "เอกสาร" ของใบสั่งขาย

สถานะ: รอตรวจ · มติเจ้าของ 2026-09-25 · ไม่มี migration

## ที่มา

เจ้าของ: *"SO อยากให้ แยกส่วนแนบไฟล์ ออกมาด้วย เผื่อ ลูกค้า เพิ่มเอกสารทีหลัง"*

ก่อนหน้านี้ใบสั่งขายไม่มีที่แนบไฟล์ทั่วไปเลย ไฟล์ของใบอยู่สี่บ้านและไม่มีจอไหนเห็นครบ:

| บ้าน | เก็บที่ | แก้ได้เมื่อ |
|---|---|---|
| ยืนยันคำสั่งซื้อ | `sales_orders.confirmAttachments` (mig 0285) · ใบเก่าก่อน 0285 อยู่ที่ `quotations.wonAttachments` | ตอนร่าง (ด่านยื่นอนุมัติ) |
| หลักฐานการชำระ | `sales_order_installments.evidence[]` + `taxInvoiceFile` | แท็บการชำระ |
| สัญญา | แถว `attachments` ของสัญญาที่ผูก (`serviceContractId`) | แท็บสัญญา / หน้าสัญญา |
| **แนบเพิ่ม (ใหม่)** | แถว `attachments` entity **`sales_order`** | ทุกสถานะ ยกเว้นใบยกเลิก |

## มติ (AskUserQuestion · เลือกทางที่แนะนำทั้งสามข้อ)

1. **แท็บใหม่ "เอกสาร"** ถัดจากภาพรวม (แบบหน้าดีล) — รวมไฟล์ทุกบ้านของใบให้เห็นที่เดียว + ปุ่มแนบเพิ่ม ·
   ตัวเลขบนหัวแท็บ = จำนวนไฟล์ทุกบ้าน
2. **ไฟล์ยืนยันคำสั่งซื้อคงที่เดิม ตรึงตอนอนุมัติ** — ของที่ลูกค้าส่งมาทีหลังเข้ากลุ่ม "แนบเพิ่มหลังออกใบ"
   ⇒ ด่านยื่นอนุมัติไม่ถูกแตะ ไม่ต้องย้ายข้อมูลเก่า
3. **แนบ = คนที่แก้ใบได้** (เจ้าของดีล/ผู้จัดการในสาย/แอดมิน · `canEditSalesPlanning` + ขอบเขตแก้ของดีล) ทุกสถานะ
   ยกเว้นใบยกเลิก · **อ่าน = คนที่เห็นใบ** · **ลบ = คนแนบเอง (ที่ยังแก้ใบได้) หรือแอดมิน**

## กติกาที่ตัดสินตอนสร้าง (ยังไม่ได้ถามเจ้าของ)

- **สิทธิ์ตัดสินผ่านดีลของใบ ไม่ใช่แถวใบ** — `sales_orders` ไม่มี `team` และ `ownerId` เป็นสำเนาตอนอนุมัติ (mig 0294)
  ⇒ ไม่ลงทะเบียนใน `SALES_ATTACHMENT_TABLE` (`lib/sales/salesOrderAttachmentAccess.js`)
- **ฉบับ Rev.** เป็นแถวใหม่ ⇒ ไฟล์แนบเพิ่มย้ายตามไปใบ Rev. หลัง RPC สำเร็จ (แบบเดียวกับ FM-SA-04) · ใบเดิม (`revised`)
  แนบ/ลบไม่ได้ · ย้ายล้ม = Rev. ยังสำเร็จ + warning + audit (ไฟล์ค้างอยู่ใบเดิม ต้องย้ายด้วย SQL)
- **แอดมินข้ามด่านสถานะได้** (เก็บกวาดไฟล์ที่แนบผิดใบ) — จอบอกเหตุพร้อมหมายเหตุว่าเป็นทางเก็บกวาด
- **ลบใบ / ลบใบเสนอราคาต้นทาง / ลบดีลแบบบังคับ** กวาดไฟล์แนบเพิ่มของใบที่หายตาม cascade (`purgeSalesOrderFiles` ไม่ throw)
- เอกสาร Google ของใบที่ยกเลิก = ให้สิทธิ์ Drive แค่อ่าน · จอไม่เปิดปุ่มสร้างเอกสาร Google (อัปไฟล์อย่างเดียว)
- กลุ่มที่อ่านอย่างเดียวมีปุ่ม "ไปแท็บการชำระ/สัญญา" ไม่เปิดทางแก้ที่สอง
- ไฟล์สัญญาต้องผ่านด่านของสัญญาเอง (`canViewSalesAttachment`) ก่อนเข้าลิสต์ — ตัวเดียวกับ proxy ไฟล์
