09ออกเป็นเอกสาร — เข้ามาตรฐานเอกสารของระบบ

PDR ไม่ได้พิมพ์ด้วยเปลือกของตัวเอง แต่ลงทะเบียนเป็น มาตรฐานเอกสารตัวที่ 5 ต่อจากใบเสนอราคา · ใบสั่งขาย · ใบแจ้งสรรพสามิต · ไทม์ไลน์โครงการ

ที่ระบบมีอยู่แล้วและใช้ต่อได้lib/documentStandards.js
ฟังก์ชัน documentStandardFormLine() คืนค่ารูปแบบ FM-RD-01: Rev. No.02. 06/02/2569 — ตรงกับหัว PDR ทุกตัวอักษร ⇒ ไม่ต้องเขียนตัวประกอบหัวเอกสารใหม่เลย
  • รหัสแบบฟอร์ม · เลขรุ่น · วันที่มีผล — แก้ที่หน้าตั้งค่า ไม่ใช่ในโค้ด
  • โลโก้และหัวกระดาษจาก printHeader ชุดเดียวกับใบเสนอราคา
  • บล็อกลายเซ็นและรายงานความพร้อมลายเซ็นที่มีอยู่แล้ว
  • หน้าพรีวิวในตั้งค่ามาตรฐานเอกสาร — ดูก่อนประกาศใช้รุ่นใหม่ได้

PDR — เอกสารที่พิมพ์ออกมาA4 · 3 หน้า
หน้าตาตรงกับฟอร์มกระดาษเดิม — คนที่เคยใช้กระดาษเปิดมาแล้วต้องอ่านได้ทันที ไม่ใช่เอกสารหน้าใหม่ที่ต้องเรียนรู้ซ้ำ
  • ช่องที่ระบบเติมให้ พิมพ์เป็นค่าจริง ไม่ใช่เส้นประ
  • ช่องที่เว้นว่างไว้ พิมพ์เป็นเส้นให้เขียนมือ — ใบที่กรอกไม่ครบยังใช้เป็นกระดาษได้
  • สถานะพิมพ์เป็นคำของฟอร์ม (Open / In Progress / Sample Sent / Closed)
  • ตารางลายเซ็น 7 แถว — ชื่อและวันที่เติมจากคนที่เซ็นในระบบแล้ว ที่เหลือเว้นให้เซ็นมือ
