  • ยอด ฿0.00 อ่านเหมือน “ใบไม่มีมูลค่า” ทั้งที่แปลว่ายังไม่ได้ตั้งราคา
  • ไม่มีจุดยึดสายตา — ทุกคอลัมน์น้ำหนักเท่ากันหมด
