# ด่านรายแถว — โหลดกับตรวจต้องอยู่ในจังหวะเดียว

> สถานะ: **กำลังดำเนินการ** · ตรวจกับโค้ดเมื่อ 2026-08-16 · ย้ายแล้ว 1 handler · เพดาน ratchet 107

## กฎ

handler ที่แก้ของ "รายใบ" บนตารางที่มีเจ้าของ/ทีม ให้ใช้ตัวเดียว:

```js
import { loadScoped } from '@/lib/scopedRow';

const { row: deal, response } = await loadScoped(supabase, 'sales_deals', id, user, 'edit');
if (response) return response;   // 404 / 403 / 500 มาพร้อมแล้ว
```

ตารางที่ลงทะเบียนแล้ว: `sales_deals` · `quotations` · `sales_orders` · `sales_leads` · `projects`
(ดู `SCOPED_TABLES` ใน [`lib/scopedRow.js`](../webapp/src/lib/scopedRow.js))

## ทำไม

🐞 **ตรวจระบบ 2026-08-16 (รอบด่านรายแถว):** รอบก่อนพิสูจน์ได้แค่ว่า "ทุก route มีด่าน"
พอถามต่อว่า **ด่านนั้นตรวจถึงระดับแถวไหม** กลับ **ตรวจสอบด้วยเครื่องไม่ได้เลย**

ลองสแกนสองวิธี ให้ false positive ทั้งคู่ (บันทึกไว้ที่ `audit/11-row-guards.md`):
- ไล่จากชื่อฟังก์ชันด่าน → พลาด `inPmProjectScope` · `withdrawFromExecError` · `projectWriteBlockedError`
- ไล่จากการไหลของตัวแปร → พลาดเพราะด่านจริงมักตรวจ **entity แม่** หรือ **payload** ไม่ใช่แถวที่โหลด

สาเหตุร่วม: ทุก handler เขียนด่านด้วยรูปของตัวเอง ⇒ ไม่มีรูปกลางให้เครื่องจับ

⇒ ทางแก้คือทำให้ **"ถือแถวไว้โดยยังไม่ผ่านด่าน" เขียนไม่ออก** — `loadScoped` รวมสอง
จังหวะเป็นหนึ่ง ไม่มีช่วงกลางให้ลืม

## กับดักที่ฝังไว้ในตัวช่วยแล้ว

⚠️ **ใบเสนอราคา/ใบสั่งขายตรวจผ่าน "ดีลที่สังกัด" ไม่ใช่ตัวใบ** — `scopeOf` เป็นตัวบอกว่า
เอา object ไหนไปตรวจ · ตารางพวกนี้จึง `select` แบบ join ดีลมาด้วยเสมอ (มีเทสต์ล็อกไว้:
ลืม join = `scopeOf` ได้ `undefined` แล้ว 403 ทุกใบ)

⚠️ **ใบที่ไม่มีดีล = พิสูจน์สิทธิ์ไม่ได้ ⇒ ปฏิเสธ** ไม่ใช่ปล่อยผ่าน · เส้นทางที่ตั้งใจให้มีใบ
ไร้ดีลต้องเขียนด่านของตัวเอง ไม่ใช้ตัวนี้

⚠️ **อ่านฐานพลาด = 500 ไม่ใช่ 404** — "ถามไม่สำเร็จ" กับ "ไม่มี" คนละเรื่อง กลืนเป็น 404
แล้วผู้ใช้จะไปไล่หาของที่ยังอยู่ครบ (บทเรียนเดียวกับ `registrationRequirements` / `projectsRepo`)

⚠️ **ไม่ใช่ตัวแทนของด่านทั้งหมด** — เส้นที่ตรวจ entity แม่ (ไฟล์แนบ) หรือคุมด้วย cap ของ
โมดูล (mgmt · ทะเบียนกลาง · สหมิตร) ยังใช้ด่านของตัวเองตามเดิม

## การย้ายของเก่า — ratchet ไม่ใช่การรื้อ

กฎ 6 ใน [`systemRules.test.mjs`](../webapp/src/lib/systemRules.test.mjs) นับจุดที่ยัง
`.from(<ตารางในทะเบียน>).select().eq('id', …)` เอง แล้วบังคับว่า **ลดได้อย่างเดียว**

เพดานตั้งต้น **107** — ตัวเลขนี้รวมทั้ง GET และจุดที่ตรวจสิทธิ์ถูกต้องอยู่แล้ว
มันวัด *"รูปแบบที่ตรวจสอบด้วยเครื่องไม่ได้"* ไม่ใช่ *"จุดที่ผิด"*

⇒ ของใหม่ต้องใช้ `loadScoped` · ของเก่ารูดลงตอนที่ไปแตะไฟล์นั้นอยู่แล้ว ไม่ต้องรื้อทีเดียว
