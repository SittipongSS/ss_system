# กฎที่มีเทสต์บังคับแล้ว

> สถานะ: **เสร็จสมบูรณ์** · ตรวจกับโค้ดเมื่อ 2026-08-30

ทุกข้อในนี้เคยเป็นกฎที่ทีมตัดสินไปแล้วและเขียนไว้ในคอมเมนต์ — แต่บังคับด้วยความจำของคนล้วน
การตรวจระบบ 2026-08-16 พบว่ากฎแบบนี้**หลุดไปแล้วอย่างน้อยสองข้อ** (ด่านสิทธิ์ของ route ที่
สตรีมไฟล์ถูกก๊อปเป็นชุดที่สอง · โมดัลอนุมัติราคาผลิตไม่บอกผลลัพธ์) ⇒ ยกมาเป็นเทสต์

ทั้งหมดอยู่ใน [`src/lib/systemRules.test.mjs`](../webapp/src/lib/systemRules.test.mjs) — `npm test`

| กฎ | ตกเมื่อ | ทางออกที่ถูกต้อง |
|---|---|---|
| **1. ทุก API route ต้องมีด่านสิทธิ์** | เพิ่ม route ที่ไม่เรียก `can*`/`require*` และไม่ได้ประกาศเหตุผล | เรียกด่าน หรือเพิ่มลง `ROUTES_WITHOUT_OWN_GUARD` พร้อมเหตุผล |
| **2. `ADMIN_LOCKDOWN` ต้องเป็น `true`** | แก้เป็น `false` | ถ้าจะปิดจริงต้องแก้เทสต์ด้วย = มีร่องรอยใน PR |
| **3. ห้ามเขียน `frozenAt: null`** | มีที่ไหนปลดล็อกยอดงวดที่ freeze แล้ว | อย่าปลดล็อก — ออก Rev. ใหม่แทน (ได้ SO id ใหม่ งวดชุดใหม่) |
| **4. จออนุมัติต้องบอกผลลัพธ์** | จอที่ยิงคำสั่งอนุมัติแต่ไม่ผ่าน `approvalPrompt` | เรียก `approvalPrompt` หรือตัวช่วยของมัน |
| **5. ช่องที่พิมพ์บนเอกสารต้องล้างการอนุมัติ** | เพิ่มช่องใน `QUOTATION_APPROVAL_INVALIDATING_FIELDS` แล้วไม่ได้ต่อเข้า `contentChanged` | ต่อให้ครบทั้งสองที่ |
| **6. โหลดแถวรายใบต้องผ่าน `loadScoped`** | handler โหลดแถวเองเกินเพดาน | ใช้ `loadScoped(supabase, table, id, user, mode)` |
| **7. สร้างสูตรจากกลิ่นต้องส่งลูกค้า** | `createFormula` ที่มี `scentId` แต่ไม่มี `customerId` | ส่งลูกค้าไปด้วยเสมอ |
| **8. หน้าที่บอกว่า "ไม่มีสิทธิ์" ต้องใช้ `AccessDenied`** | หน้าเขียนกล่องปฏิเสธของตัวเอง | ใช้จอกลาง หรือลงทะเบียนใน `PAGES_WITH_OWN_DENIAL_TEXT` พร้อมเหตุผล |
| **9. ห้าม `return null` ตอนด่านสิทธิ์ไม่ผ่าน** | หน้าคืน null ในเงื่อนไข `can*` | `accessState()` + `<AccessDenied />` |

## ทำไมเป็นเทสต์ที่อ่านซอร์ส ไม่ใช่เทสต์ที่รันโค้ด

สิ่งที่ต้องกันคือ **"ลืมเขียน"** ไม่ใช่ "เขียนแล้วทำงานผิด" — route ใหม่ที่ลืมด่านสิทธิ์
ไม่มีเทสต์พฤติกรรมไหนจับได้ เพราะไม่มีใครเขียนเทสต์ให้ route ที่เพิ่งลืม

**ข้อเสียที่ยอมรับ:** ผูกกับรูปของโค้ด ⇒ refactor แล้วอาจตก · ถ้าตก **ให้แก้เทสต์ให้ตรงกับ
รูปใหม่หลังยืนยันว่ากฎยังอยู่จริง ไม่ใช่ลบทิ้ง**

## กับดักที่เจอตอนเขียนเทสต์พวกนี้

⚠️ **ต้องตัดคอมเมนต์ก่อนมองหาชื่อฟังก์ชัน** — รอบแรกเทสต์ข้อ 4 ไม่จับ เพราะไฟล์ที่ถอด
`approvalPrompt` ออกแล้วยังผ่าน เนื่องจากคอมเมนต์ข้างบนเขียนคำว่า "กฎใน lib/approvalPrompt"

⚠️ **ต้องอ่านทั้งคำสั่ง ไม่ใช่บรรทัดเดียว** — นิพจน์ `contentChanged` ยาวสามบรรทัด ตัดแค่
บรรทัดแรกจะพลาด `notes`/`quoteDate`/`validUntil`/`docLanguage`

⚠️ **ไฟล์ alias ต้องนับเป็นข้อยกเว้น** — `export { GET, POST } from "…"` คู่กับ
`export const dynamic` (Next ไม่รับ re-export ของ segment config)

## ทดสอบตัวเทสต์เองแล้ว

ข้อ 8/9 มาจากกฎ [ui-visibility-rule.md](ui-visibility-rule.md) (มติ 2026-08-30)

ทุกข้อถูกลองทำให้ตกจริงก่อนส่ง: เพิ่ม route ไร้ด่าน · ปิด `ADMIN_LOCKDOWN` · เขียน
`frozenAt: null` · ถอด `approvalPrompt` ออกจากจออนุมัติ · ถอด `docLanguage` ออกจาก
