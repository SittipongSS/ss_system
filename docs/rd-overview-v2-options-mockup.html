  • ทั้งสามแบบข้างล่าง ไม่ต้องแก้ฐานข้อมูลเลย — ใช้ฟิลด์ที่ API ส่งมาอยู่แล้วทั้งหมด

คิวถัดไป

ตารางเดิม ไม่เปลี่ยน
ได้อะไรตัวเลขตรงกับภาระจริง — "8 ใบ" อ่านไม่ออกว่าหนักแค่ไหน แต่ "19 กลิ่น" อ่านออกทันที · เห็นคอขวดว่าอยู่ขั้นไหน · ยังไม่ใช่กราฟ (เคารพข้อจำกัดที่หน้านี้ตั้งไว้เอง)
ข้อจำกัดใบที่ไม่ใช่พัฒนากลิ่น (สอบถามข้อมูล · ขอเอกสาร) ไม่มีบรรทัด ⇒ นับเป็นกลิ่นไม่ได้ ต้องโชว์คู่กันสองหน่วย ("19 กลิ่น · 4 ใบไม่มีบรรทัด") ไม่งั้นตัวเลขจะไม่ครบแล้วไม่มีใครรู้

ผมแนะนำ: ก แล้วค่อย ค

  • ก ตอบคำถามที่ขาดหายที่สุด (ทั้งหน้าไม่มีชื่อคนสักที่) และต่อยอดตรงกับงานถัดไปในลิสต์ — มอบหมายงาน RD รายคน
  • ค แก้หน่วยของตัวเลขให้ตรงกับภาระจริง ทำต่อได้ทันทีเพราะใช้ items ที่มีอยู่แล้ว
  • ข เก็บไว้ทีหลัง — ตอนนี้ 8 ใบจาก 15 ยังไม่มีใครให้วัน ปฏิทินจะโล่งจนอ่านผิด
