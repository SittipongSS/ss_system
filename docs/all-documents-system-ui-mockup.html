#ช่องว่างอาการที่ผู้ใช้เจอเสนอ
1 จัดซื้อไม่มีชุดชนิดเอกสารของตัวเอง ส่งใบขอเอกสารถึงจัดซื้อแล้วเลือกได้แต่ IFRA/COA/MSDS ซึ่งจัดซื้อออกให้ไม่ได้ — เหลือทางเดียวคือ "อื่น ๆ" ทะเบียนคำศัพท์ชุดที่ 3 (docVocabulary รองรับอยู่แล้ว) + ให้ฟอร์มเลือกชุดตามฝ่ายปลายทาง
2 ไม่มีจอที่เห็นเอกสารครบทั้งบริษัท แผงรวมมีเฉพาะ "ของดีล" · เอกสารลูกค้า/สินค้า/ทะเบียนสรรพสามิต อยู่คนละจอ ไม่มีที่ไหนตอบว่า "ทั้งบริษัทขาดอะไรอยู่" จอ ทะเบียนเอกสาร ในโมดูลฐานข้อมูล — กรองตามฝ่าย · ชนิด · สถานะ (มี/รอ/หมดอายุ)
3 อายุเอกสารมีชนิดเดียว ภ.พ.20 · ใบอนุมัติสรรพสามิต · หนังสือมอบอำนาจ ไม่มีอายุกำกับ ⇒ ไฟล์ปีที่แล้วยังติ๊กเขียว เติม DOC_VALIDITY_MONTHS ตามที่ธุรกิจใช้จริง + จอรวม "ใกล้หมดอายุ" (§05)
4 เอกสารหมดอายุไม่มีทางเตือน รู้ตอนจะใช้แล้วใช้ไม่ได้ — ต้องขอลูกค้าใหม่แล้วรอ ซึ่งดีลรออยู่ cron เช้าเข้ากล่องแจ้งเตือนรายคน แบบเดียวกับที่ลีดค้างคิวใช้อยู่แล้ว
5 ขอเอกสารจากลูกค้าไม่ได้ในระบบ เอกสารลูกค้าทั้ง 8 ชนิดต้องไปขอทาง LINE/อีเมลเอง แล้วกลับมาแนบเอง — ไม่มีร่องรอยว่าขอไปเมื่อไร ทวงกี่ครั้ง หัวข้อคำร้อง "ขอเอกสารจากลูกค้า" ที่ผู้รับผิดชอบเป็น AE เอง — ใช้โครงบรรทัด+สายเดียวกับ ม-85 ทั้งหมด
ข้อ 1 กับ 3 เป็นการเติมทะเบียน ไม่ต้องแตะโครงเลย · ข้อ 2 กับ 4 เป็นจอ/งานเบื้องหลัง ที่มีของกลางให้ยืมอยู่แล้ว · ข้อ 5 ใหญ่สุด — เป็นหัวข้อคำร้องใหม่ ควรตัดสินก่อนว่า ธุรกิจอยากให้การทวงเอกสารลูกค้าอยู่ในระบบไหม
