ขอเอกสาร — ทุกขั้นตอนของ SA และ RD

วาดตาม flow ที่ตัดสินแล้ว (ม-83 … ม-88) และตรงกับโค้ดที่ส่งไปแล้วจริงทุกจอ — SA ยื่นจากบริหารงานขาย · RD ตอบจากวิจัยและพัฒนา · ไฟล์ที่ได้ไหลเข้า แท็บเอกสารของดีลและโครงการเอง

flow ตามมติผู้ใช้ 2026-08-08 (ม-88) — "SA ยื่นคำร้อง เลือกขอเอกสาร ใส่ข้อมูล ลูกค้า/โครงการ ดีล/ใส่รายละเอียดที่เกี่ยวข้อง QT SO FG (ถ้ามี)/ใส่รายการเอกสาร IFRA COA MSDS อื่นๆ/ใส่รายละเอียดเพิ่มเติม → RD รับเรื่อง ใส่วันกำหนดส่ง … ถามตอบกันได้ 2 ฝ่าย → RD แนบเอกสาร (เอกสารไปสู่แท็บเอกสารในโครงการ ดีลนั้นด้วย) → SA กดรับ"

00แผนที่ — 8 ขั้น ใครทำอะไร ที่ไหน

SA บริหารงานขาย

  1. ① เปิดคำร้อง — หัวข้อ "ขอเอกสาร" (ฝ่าย RD ถูกเลือกให้เอง · ม-87)
  2. ② กรอกฟอร์ม — ดีล → ลูกค้า/โครงการเติมเอง · QT/SO/FG (ถ้ามี) · รายการเอกสาร · วันคาดหวัง (บังคับ) · แนบไฟล์ได้เลย
  3. ③ บันทึกร่าง → ส่ง — เลขที่ RQ-… ออกตอนส่ง
  4. ⑤ ถามตอบ ในเธรดได้ตลอด
  5. ⑧ กดรับ "ได้รับแล้ว" — ยืนยันว่าไฟล์ใช้ได้จริง → ปิดเรื่อง

RD วิจัยและพัฒนา

  1. ④ รับเรื่อง + วันกำหนดส่ง (บังคับ · ม-83) — ข้อมูลไม่ครบ → ตีกลับ
  2. ⑤ ถามตอบ ในเธรดได้ตลอด
  3. ⑥ แนบไฟล์ที่แถว → กดส่งเอกสาร รายแถว
  4. ให้ไม่ได้ → กด "ให้ไม่ได้" + เหตุผล (ติดแถวให้ SA เห็น)

DOC ปลายทางของไฟล์

  1. ⑦ ไฟล์ไหลเอง เข้าแท็บเอกสารของดีล — แหล่ง "เอกสารจากคำร้อง"
  2. และแท็บเอกสารของโครงการ (รวมทุกดีลข้างใน)
  3. แถวที่ยังไม่ส่ง = "รอเอกสาร" นับเป็นของที่ยังไม่มา
