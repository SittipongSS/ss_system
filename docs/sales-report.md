# รายงานยอดขาย (`/sa/targets/report`)

> สถานะ: **รอตรวจ** · ตรวจกับโค้ดเมื่อ 2026-09-22 · รื้อรอบสาม (ตัวเลือกงวดแบบหน้าลีด + Excel + layout ใหม่) รอ UAT กับหัวหน้าฝ่ายขาย

หน้าค้นแล้วเอาออกตามงวด — เป้าเทียบยอดขายจริง แล้วไล่ลงถึงใบสั่งขาย · เปิดได้เฉพาะ `salesplan:target`
(หัวหน้าฝ่ายขาย + admin) ทั้งจอและไฟล์ · **ไม่ใช่ส่วนขยายของแท็บผลงานขาย** (มติ 2026-08-26)

## ไฟล์ที่เกี่ยวข้อง

## กติกาตัวเลข (มติที่คงไว้)

- ยอดที่นับ = `sales_orders.actualAmount` (ยอดหน้าใบ − VAT ท้ายใบ) ของใบ `approved` · ใบย้อนหลัง (origin historical) ไม่นับ
- งวดของยอด = วันอนุมัติตามเวลาไทย · เจ้าของ = `ownerId` ที่แช่ตอนอนุมัติ · ทีม = ทีมของดีล
- ยอดกรอกย้อนหลัง (`sales_history`) **ทับ** ยอดใบของเดือนนั้นทีละระดับ · ใบในเดือนนั้นขึ้น "ไม่นับ · เดือนนี้ใช้ยอดกรอก"
- เดือนที่ยังไม่จบไม่เข้าผลรวม/%/ส่วนต่าง (โหมดรายเดือน/ทั้งปี) · % และส่วนต่างเทียบเฉพาะเดือนที่ **แถวนั้น** มีเป้า
- ทบยอดรีเซ็ตทุกต้นปี · **เดือนเดียวโหลดแกนตั้งแต่ ม.ค.** (เดิมทบยอดเริ่มที่ต้นช่วงที่เลือก — "ไตรมาสนี้" ให้เลขต่างจาก "ปีนี้" · แก้ 2026-09-22)
- ใบรออนุมัติเป็นก้อนแยก ลงวันนี้เสมอ ⇒ โชว์เฉพาะงวดที่คลุมวันนี้ · ไม่เข้าขายจริง/ทบยอด/%/ส่วนต่าง
- ตามทีม/ตามคนคิดเฉพาะเดือนที่แยกยอดรายคนจริง (ก่อน ส.ค. 2026 ยอดอยู่ระดับบริษัท)
- ขั้นบัญชีตามลำดับ 30/08: ปิดใบแล้ว / รอปิดใบ / **ไม่ผ่านบัญชี (ใบยอด 0 ไม่เข้าแกนบัญชี)**

## งวด "รายเดือน | ช่วงวัน" (มติผู้ใช้ 2026-09-22)

- รายเดือน = MonthPicker เดือนเดียว · ติ๊ก "ทุกเดือน" = ทั้งปี (ค่าตั้งต้น) — ข้ามปีทำได้ผ่านช่วงวันเท่านั้น
- ช่วงวัน = DayRangePicker (ชิปเดียวกับหน้าลีด) · จุดใต้วัน = วันที่มีใบอนุมัติ (`markedLabel`)
- **ช่วงวันปันเป้าตามจำนวนวัน**: เป้าเดือน × (วันในช่วงที่ไม่เกินวันนี้ ∩ เดือน) ÷ วันทั้งเดือน · ทุกระดับ · ปัดสตางค์รายแถวรายเดือน
- ช่วงวันไม่มีทบยอด · เดือนกรอกย้อนหลังที่ช่วงคลุมไม่ครบ = นับเฉพาะใบในช่วง และ **ไม่เทียบเป้า** (เป้าเดือนนั้น = 0)

## หน้าจอ (รื้อ 2026-09-22)

หัว (งวด + ดาวน์โหลด Excel) → แถบตัวเลข (ไม่มีไอคอน) → ข้อความกำกับ (เดือนยังไม่จบ · ยอดบริษัทไม่ตรงรายคน รายเดือน ·
เดือนคลุมไม่เต็ม) → **แยกยอด** (ตามเดือน/ตามทีม/ตามคน) → ใบรออนุมัติ → ใบที่อนุมัติแล้ว (กางทันที แบ่งหน้า 10 แถว)

- กดขายจริงในตารางแยกยอด = กรองรายการใบให้เหลือใบของยอดนั้น + บรรทัด ✓ ตรง / ✗ ต่าง (บอกเหตุถ้ามาจากยอดกรอกมือ)
- ตามทีม/ตามคนมีแถว "ยอดบริษัท (เดือนเดียวกัน)" และ "ยังไม่ลงทีม/คน" ใต้แถวรวม
- ด่าน "กดค้นหาก่อนเห็นใบ" ของ 2026-08-27 ถูกแทนด้วย Pager (ปัญหาเดิมคือหน้าสูง 6,000px — แก้ด้วยการแบ่งหน้าแทน)

## ไฟล์ Excel

ชีต: สรุปรายเดือน · รายทีม · รายคน · ใบสั่งขาย (ทุกใบในงวด ไม่ขึ้นกับตัวกรองบนจอ) · รออนุมัติ (ถ้ามี)

ชีต "ใบสั่งขาย" เรียงคอลัมน์ตามมติผู้ใช้ 2026-09-22 (เทสต์ล็อกไว้): **# › งวด › วันที่อนุมัติ › ประเภทธุรกิจ › ประเภทดีล ›
QT › SO › ลูกค้า › บรรทัด › ยอดที่นับ › VAT › ยอดหน้าใบ › ขั้นบัญชี › หมายเหตุ › ผู้รับผิดชอบ › ทีม** · ลิงก์กลับหน้าใบอยู่บนเลข SO ·
หมายเหตุรวม "ไม่คิดเงิน" กับ "ไม่นับ · เดือนนี้ใช้ยอดกรอกย้อนหลัง"

**ประเภทธุรกิจ** = `sales_deals.line` (สินค้า (Products) / บริการ (Services)) · **ประเภทดีล** = `sales_deals.dealType`
(SCENT / NPD / RE-ORDER / OTHER) ของดีลของใบ — มีทั้งบนจอ (คอลัมน์ + ตัวกรอง + จัดกลุ่ม) และในไฟล์ · ดีลที่ยังไม่ระบุ = ขีด
(ห้ามใช้ `dealTypeOf` ซึ่งตีค่าว่างเป็น NPD)
หัวทุกชีตประทับงวด/ผู้โหลด/เวลาไทย · ชื่อไฟล์ `รายงานยอดขาย_<งวด>.xlsx`
