07กติกาที่ฟอร์มต้องบังคับ

กติกาทำไมบังคับที่
ติ๊กด่วน → ต้องกรอกเหตุผล กระดาษเขียนไว้เอง · ติ๊กด่วนได้ฟรีเมื่อไร ทุกใบก็ด่วนภายในสองเดือน แล้วธงเลิกมีความหมาย API
ติ๊ก “มีภาพประกอบ” → ต้องแนบไฟล์ ปล่อยให้ติ๊กแล้วไม่แนบ = RD ตามหาภาพที่ไม่มีอยู่จริง ซึ่งแย่กว่าติ๊กว่าไม่มีตั้งแต่แรก ตอนกดส่ง
ติ๊ก “เอกสารส่งออก” → ช่องระบุโผล่ “เอกสารส่งออก” เฉย ๆ ตอบไม่ได้ว่าประเทศไหน ชนิดอะไร ฟอร์ม
Modification / Cost Reduction → ช่องรหัสก่อนหน้าโผล่ กระดาษมีเส้นเขียนต่อหลังทั้งสองตัวเลือก ฟอร์ม
ซ่อนแล้วห้ามลบค่า ผู้ใช้สลับประเภทไปมาแล้วค่าที่พิมพ์ไว้ต้องไม่หาย · จอแสดง/เอกสารยังโชว์ค่าที่มีอยู่เสมอ ฟอร์ม
ติ๊ก Scentotype ออก → ข้อความหายตาม เก็บเฉพาะตัวที่ติ๊กไว้จริง ไม่ค้างเป็นข้อมูลผีที่ไม่มีใครเห็นแต่ยังอยู่ใน DB API
บล็อกบรีฟห้ามเกิน qty ของ SO เขียนบรีฟ 5 ทางบนใบที่ขาย 3 กลิ่น แปลว่าอย่างน้อยสองทางจะไม่มีใครทำ และไม่มีอะไรบอกว่าทางไหนถูกตัด · น้อยกว่าได้ (บรีฟรวม) ฟอร์ม + API
“จำนวนกลิ่นที่ต้องการพัฒนา” อ่านจาก SO เสมอ ไม่ใช่จำนวนบล็อกบรีฟ — บรีฟรวมจะทำให้ 1.12 ขึ้นว่า 1 กลิ่นทั้งที่ลูกค้าจ่ายมา 3 API
สลับโหมดบรีฟห้ามลบของที่พิมพ์แล้ว รวม → รายกลิ่น: ก้อนแรกคงเนื้อเดิม ที่เหลือว่าง · รายกลิ่น → รวม: เตือนว่าจะเหลือก้อนไหน ไม่ใช่ทิ้งเงียบ ฟอร์ม

  • 1 · “วันที่ร้องขอ” เข้าทะเบียนแล้ว เป็นช่อง derived อ่านจาก submittedAt ⇒ โผล่พร้อมกันทั้งฟอร์ม หน้ารายละเอียด และกระดาษ · ถอด hardcode createdAt ที่หัวเอกสารออกแล้ว ไม่มีสองแหล่งอีก
  • 2 · ปุ่มสลับโหมดบรีฟไม่ลบของที่พิมพ์แล้ว — ปุ่มมีอยู่ก่อนแล้วแต่ ล้างทุกก้อนทุกครั้ง แม้แต่ตอนแยก 1 → N ซึ่งไม่มีเหตุผลให้ทิ้งอะไรเลย · กติกาย้ายไป switchBriefMode() · รวบแล้วมีก้อนที่กรอกไว้จะหายจริง ⇒ ถามก่อนด้วยโมดัลของบ้าน
