# ค่าว่างพูดคำเดียวกันทั้งระบบ: N/A

สถานะ: `เสร็จสมบูรณ์` (มติผู้ใช้ 2026-08-14)

## กฎ

**ทุกที่ที่ *แสดงผล* ค่าที่ไม่มี ให้ขึ้นว่า `N/A`**

```js
import { naText, NA, isBlank } from "@/lib/format";

naText(row.taxId)        // มีของ → คืนของเดิม · ว่าง → "N/A"
{cond ? value : NA}      // ternary
<span>{NA}</span>        // ขีดที่เคยเขียนเป็นข้อความใน JSX
```

ที่มา: ก่อนหน้านี้ "ไม่มีค่า" ถูกเขียนกระจายเป็น `-` `—` `.` แล้วแต่คนเขียน
(ตรวจ 2026-08-14: **355 จุด 114 ไฟล์**) ⇒ ตารางเดียวกันเห็นหลายแบบในแถวเดียว
และคนอ่านแยกไม่ออกว่า "ยังไม่กรอก" กับ "กรอกขีดมา" ต่างกันไหม

🔴 **N/A บอกว่า "ระบบถามแล้วแต่ไม่มีคำตอบ"** — ขีดเปล่า ๆ อ่านได้ว่าเป็นเส้นคั่น
เป็นสัญลักษณ์ หรือเป็นค่าจริงก็ได้ (เหตุผลเดียวกับที่ PDR เลือก N/A แทนเส้นประ
ตั้งแต่มติ 2026-08-07 — รอบนี้คือขยายกฎเดิมให้ทั้งระบบ)

## ⚠️ ใช้กับ "ที่แสดงผล" เท่านั้น

| ที่ | ทำอะไร |
|---|---|
| ตาราง · หน้ารายละเอียด · การ์ด · ป้าย | **N/A** |
| `<input readOnly>` / `disabled` | **N/A** (มันคือการแสดงผล) |
| **`<input>` ที่พิมพ์ได้** | **ห้ามใส่ N/A ลง `value`** — ปล่อยว่าง บอกด้วย `placeholder` |

🪤 ใส่ `N/A` ลง `value` ของช่องที่แก้ได้ = กด Save แล้วคำว่า `N/A` ลง DB เป็นข้อความจริง
⇒ แยกไม่ออกว่า "ไม่มีข้อมูล" หรือ "คนพิมพ์ N/A" · ช่องตัวเลขก็พังเพราะ `N/A` ไม่ใช่ตัวเลข
· ค้นหา/กรอง/export จะเห็น N/A เป็นข้อมูลจริง

## 🔴 ข้อยกเว้นที่ต้องจำ

**`0` และ `false` ไม่ใช่ค่าว่าง** — ยอด 0 บาท จำนวน 0 ชิ้น "ไม่อนุมัติ" คือ*คำตอบ*
ไม่ใช่การไม่มีคำตอบ

```js
naText(0)      // → 0     ✅
0 || NA        // → "N/A" ❌ `||` กลืน 0 ทิ้ง
```

นี่คือเหตุผลที่ต้องมี `naText()` แทนการเขียน `value || NA` — `format.test.mjs` ตรึงไว้แล้ว

**คำที่มีความหมายเฉพาะ เก็บไว้** ห้ามยุบเป็น N/A:

- `ไม่มีกำหนด` — ไม่ใช่ลืมกรอก แต่*ไม่มี*จริง
- `ระบบ` — createdBy ที่ระบบสร้างเอง ไม่ใช่ไม่รู้ว่าใคร
- `ไม่ระบุลูกค้า` · `ไม่ต้องเสียภาษี` — ประโยคที่บอกสถานะจริง
- `emptyText` ของ picker ที่อธิบายว่ากรองอะไรออก (ดู [form-design-rules.md](form-design-rules.md))

## ⚠️ `src/lib/` ไม่อยู่ในกฎนี้

`src/lib` เป็น **ฟังก์ชันข้อมูล** กับ **ตัวประกอบเอกสาร** — ใส่ N/A ที่นั่นจะกลายเป็น
*ข้อมูล* ไม่ใช่การแสดงผล ตัวอย่างที่ห้ามแตะ:

- `requests/scope.js` คืน **id** — `requestedById: "N/A"` คือ id ปลอม
- `master/customerAr.js` คืนชื่อลูกค้าที่ถูกเอาไปเทียบ/จัดกลุ่มต่อ
- `sales/quotationMasterTemplate.js` — แตะแล้ว**กระทบลายเซ็นอนุมัติของใบเสนอราคา**
- `**Print.js` · `pdrDocument.js` — เอกสารพิมพ์มีกติกาของตัวเอง (PDR พิมพ์ N/A อยู่แล้ว)

ที่นั่นตัดสินทีละจุดด้วยมือ · `audit:ui` จึงตรวจเฉพาะ `src/app` กับ `src/components`

## ด่านกันถอยหลัง

`audit:ui` ฟ้องเมื่อเจอรูปเหล่านี้ในชั้นแสดงผล (ต้องเป็น **0** เสมอ):

```js
x || "-"            // → naText(x)
cond ? y : "-"      // → cond ? y : NA
<span>-</span>      // → <span>{NA}</span>
```

`ReadableText` ตั้งค่าปริยาย `empty = NA` ไว้แล้ว — ไม่ต้องส่ง `empty` ซ้ำ
ส่ง `null` ถ้าตั้งใจให้หายไปเลยแทนที่จะขึ้น N/A
