## การ์ด "สรุปใบนี้" ทรงใหม่

**พัฒนากลิ่น** (บนลงล่าง)
1. **ใบสั่งขาย** — หนึ่ง SO ต่อบรรทัด: เลขใบ · หลัก/แนบ (วันที่แนบ) · จำนวนกลิ่น · บรรทัดรวม "รวมที่ลูกค้าจ่าย n กลิ่น"
   ใบที่มีรอบแก้ที่ซื้อ (03-010 ของ SO แนบ) บอก "รอบแก้ n" ในบรรทัดของใบนั้น
2. **ยืนยัน x / y** — ตัวเลขนำ (ตัวเดียวกับด่านปิดใบ `soReconcile` + `scentSlotLinesOf`) ·
   โทน: ขาด = เตือน · ครบ = เขียว · เกินที่ยังไม่ระบุ = เตือน · เกินที่ระบุแถมครบ = เขียว (`soReconcileTone` เดิม)
   ใต้ตัวเลข: กลิ่นที่ยืนยัน หนึ่งต่อบรรทัด + ขั้นของแถวท้ายบรรทัด ("เสร็จแล้ว" · "รอ RD ใส่ราคา" · "รอ RD ใส่ Ingredient List") · แถวแถมมีป้าย "แถม"
3. **ขอแก้ n** — หนึ่งต้นทางต่อบรรทัด: "ALMOST HERE → #1 · #2" · บรรทัดท้าย "รอบแก้ ใช้ n · ซื้อ m" (โชว์เสมอ ไม่ใช่เฉพาะเมื่อซื้อ — มติ ม-164 ข้อ 3)
4. **ไม่เอา n** — หนึ่งกลิ่นต่อบรรทัด · แถวที่มาจากรอบแก้มีป้าย "รอบแก้"
5. **บรรทัดเล็กท้าย** — "รอลูกค้าตอบ n" (และ "รอ RD ส่งงาน n" เมื่อมีบรีฟ/รอบแก้ที่ยังไม่ส่ง)

**พัฒนาสูตร** — ข้อ 2–5 ทรงเดียวกัน ไม่มีข้อ 1 · ตัวเลขนำ = "ยืนยัน n สูตร" (ไม่มีตัวหาร) · รอลูกค้าตอบเป็นรายการหนึ่งต่อบรรทัดพร้อมกำหนดส่ง/เลยกำหนด

**ถอด:** เช็คลิสต์ "ทุกบรีฟมี direction" หลังส่งใบ (ยังอยู่ตอนร่าง/ก่อนส่ง) · แกนสามแถว "รอ<ฝ่าย> · รอ<ผู้ขอ> · ไม่ถูกเลือก" ของสองสายนี้

## ตาราง "สรุปทั้งใบ" ทรงใหม่ (สองสาย ทรงเดียว · CSS ก้อนเดียวกันตามกฎเดิม ห้ามโคลน)

- **แถวละบรรทัด:** ชื่อ · รหัส (เล็ก) | ผลลูกค้า (ป้ายสี) | ราคา/กก. (กลิ่น) หรือ กำหนดส่ง (สูตร) | ก้าวถัดไป
- **ต้นไม้รอบแก้:** แถว "ขอแก้" เป็นแม่ · แถวที่ `derivedFromItemId` ชี้มา + direction เพิ่มของรอบนั้น (`directionOfItemId` · ม-157) ซ้อนใต้เป็นกิ่ง ·
  แถวแม่บอก "แก้ n ตัว ↓"
- **แถวจบแล้ว** (ไม่เอา · เสร็จแล้ว) จาง/เตี้ย ไม่มีกล่องแนบไฟล์ · เมนู ⋯ ที่ยังใช้ได้จริงยังอยู่ (เช่น "เปลี่ยนเป็นคอนเฟิร์ม" ของ ม-164)
- **หัวกลุ่มบรีฟ (กลิ่น):** ชื่อบรีฟ · "n direction · ยืนยัน · ขอแก้ · ไม่เอา" (คำชุดเดียวกับการ์ด) · ผู้รับผิดชอบ · ปุ่ม "ส่งงาน" ของบรีฟ (คงเดิม)
- **สเปกจาก PDR (สูตร):** ขึ้นครั้งเดียวที่หัวตาราง พับได้ · ไม่พิมพ์ใต้ทุกแถว
- **ปุ่มเดียว "บันทึกคำตอบ ▾"** แทนสามปุ่ม — เมนูเลือก ยืนยัน / ขอแก้ / ไม่เอา แล้วเปิดโมดัลเดิมของก้าวนั้น (เหตุผล · ด่าน `over_paid` · บอกผลก่อนกด #1223)
- **กดแถว = กางรายละเอียด:** ลูกค้าบอกว่า · โจทย์รอบนี้ · ไฟล์แนบ (+ ช่องลากวาง) · ส่งเป็นสินค้า · วันที่ส่ง/ตอบ ·
  แถวพับมีไอคอนเล็กบอกว่ามีโน้ต/ไฟล์ (ไม่ต้องกางเพื่อรู้ว่ามี)
- **ถอด:** รางจุด · คอลัมน์ "ค้างมา" ของแถวที่จบแล้ว · บรรทัด "ส่งเป็นสินค้า …" บนแถวหลัก (ย้ายเข้ารายละเอียด)
