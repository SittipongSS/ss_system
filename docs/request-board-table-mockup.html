ตารางสรุปทั้งใบ — รื้อรอบสอง

ต่อจาก IS-26080021 · รอบแรกยุบการ์ดซ้ำออกไปแล้ว รอบนี้แก้ตัวตาราง

1 · ที่เหลือจากภาพล่าสุด

  1. 1หัวตารางเป็นแถบสีคั่นกลางการ์ดขาว อ่านเหมือนตารางเป็นของแปลกปลอมที่ถูกวางลงในการ์ด ไม่ใช่เนื้อของการ์ด
  2. 2แถวเดียวกินความสูง 3 ชั้น แถว + ป้าย “รูป / สเปกแนบ” + คำใบ้ลาก-วาง — ทั้งที่ยังไม่มีไฟล์สักใบ
  3. 3กล่องไฟล์ว่างแต่กินที่เต็ม ป้ายบรรทัดหนึ่ง ปุ่มอีกบรรทัด คำใบ้อีกบรรทัด = 3 บรรทัดที่ไม่มีเนื้อ
  4. 4ครีมทามือ · - CHAO PHRAYA… มี · - ค้างอยู่ — ช่องว่างในข้อมูล ต้องแก้ที่ต้นทาง ไม่ใช่ CSS

3 · ที่เปลี่ยน

  1. ✓หัวตารางไม่มีแถบสี เหลือแค่บรรทัดหัวคอลัมน์ตัวเล็ก + เส้นคั่นบาง — ตารางกลายเป็นเนื้อของการ์ด ไม่ใช่ของที่วางทับ
  2. ✓ไฟล์อยู่บรรทัดเดียว ป้าย + สถานะไฟล์ + ปุ่ม เรียงกันแถวเดียว · ปุ่มอยู่ติดกับสิ่งที่มันทำ ไม่ลอยไปสุดขวา
  3. ✓ยังไม่มีไฟล์ = บอกไปเลย “ยังไม่มีไฟล์” อยู่ในบรรทัดเดียวกับป้าย — ไม่ต้องเว้นที่ว่างให้กล่องเปล่า
  4. ✓แถวสูงเท่าเนื้อ แถวที่ยุบ = บรรทัดเดียว · จัดกลาง ไม่ใช่ชิดบนแล้วเหลือที่ว่างใต้
  5. ✓คอลัมน์ 44 / 20 / 14 / 22 ปุ่มก้าวถัดไปชิดขวาเสมอ — ตาไล่จากซ้าย “อะไร → ผลเป็นไง → อยู่ขั้นไหน → ทำอะไรต่อ”
ข้อ 4 (· - ค้างในชื่อ) ไม่ได้แก้ในม็อกอัพ — เป็นข้อมูล ไม่ใช่ดีไซน์ · ชื่อแถวถูกประกอบจาก “หมวดสินค้า · ชื่อกลิ่น” แล้วมีช่องกลางที่ว่าง ⇒ ต้องไล่หาว่าใครประกอบ แล้วกรองค่าว่างทิ้งก่อน join · แยกเป็นงานของตัวเอง
ยังไม่ตัดสิน: แถวที่ ยังไม่มีทั้งสเปกและไฟล์ ควรกดกางได้ไหม — กางแล้วเจอ “ยังไม่มีไฟล์” อย่างเดียวก็เป็นการกดเปล่า · ทางเลือก: ซ่อนลูกศรไปเลยเมื่อไม่มีอะไรให้กาง
