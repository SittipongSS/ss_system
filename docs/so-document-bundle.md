# ชุดเอกสาร QT · SO · การชำระ (โหลดหลายใบเป็น ZIP)

สถานะ: รอตรวจ · มติเจ้าของ 2026-10-27 · ไม่มี migration

## ที่มา

เจ้าของ: *"อยากได้ไฟล์ QT SO เอกสารการชำระ ทำเป็นชุดๆ ได้มั้ย"*

## มติ (AskUserQuestion ทีละข้อ · เลือกทางที่แนะนำทุกข้อ)

1. **หน่วยของชุด = ใบสั่งขาย · เลือกหลายใบโหลดทีเดียว** — ZIP ไฟล์เดียว โฟลเดอร์ละหนึ่งใบ
2. **จุดกด = ทะเบียนใบสั่งขาย** (`/sales-planning/sales-orders`) — ช่องติ๊กหน้าแถว + ปุ่ม "โหลดชุดเอกสาร" หัวแผงรายการ
3. **ไฟล์แยกในโฟลเดอร์** — ไม่รวมเป็น PDF เดียว · สลิปคงไฟล์ต้นฉบับ (รูป/PDF) ไม่แปลง
4. ของที่ใส่เพิ่มในชุด เจ้าของไม่ระบุ ⇒ ตัดสินตอนสร้าง: **ใส่ใบกำกับภาษีรายงวด** (เป็นเอกสารการชำระ) ·
   **ไม่ใส่** ไฟล์ยืนยันคำสั่งซื้อ · สัญญา · แนบเพิ่มหลังออกใบ (ยังโหลดทีละไฟล์ได้ที่แท็บเอกสารของใบ)


## กติกาที่ตัดสินตอนสร้าง

- **ห่อ ZIP ที่เบราว์เซอร์ ไม่ใช่ที่ server** — Vercel ตอบ body ได้ไม่เกิน 4.5 MB ต่อคำขอ ZIP หลายใบที่มีสลิปพังแน่ ·
  เบราว์เซอร์ดึงทีละไฟล์ผ่าน proxy เดิมของแต่ละบ้าน (ด่านสิทธิ์/ด่าน path ชุดเดิม ไม่มีทางที่สอง) · `jszip` โหลดตอนกดเท่านั้น
- **PDF ฉบับที่ออกจริงเท่านั้น** (ไม่เรนเดอร์ข้อมูลสด) — ใบเสนอราคาจาก `quotations/[id]/issued/pdf` ·
  ใบสั่งขายจากเส้นใหม่ `sales-orders/[id]/issued/pdf` (ฝาแฝดของใบเสนอราคา · กติกา 409 เดียวกับ `/issued`:
  ใบที่ไม่อยู่สถานะ approved แล้วไม่ได้ PDF ฉบับล่าสุด เพราะ PDF ตรึงไม่มีลายน้ำ)
- **PDF ใบสั่งขายสร้างครั้งแรกที่มีคนขอ** (ใบสั่งขายไม่สร้าง PDF ตอนอนุมัติ) แล้วเก็บลง bucket `issued-quotation-pdf`
  โฟลเดอร์ `sales-orders/` + แถว `issued_document_pdf_artifacts` ชุดเดียวกับใบเสนอราคา ⇒ ครั้งแรกของแต่ละใบช้า ~5 วิ
- **ไฟล์ที่ขาดไม่หายเงียบ** — ใบยังไม่อนุมัติ (ไม่มีฉบับตรึง) · ใบย้อนหลัง (ไม่มีใบเสนอราคาในระบบ) · ไม่มีสิทธิ์ ·
  อ่านรายการเอกสารไม่ได้ → ลง `ไฟล์ที่ขาด.txt` + กล่องเตือนบนจอบอกจำนวน
- ติ๊กหัวตาราง = ทุกใบหลังค้นหา/กรอง **ทุกหน้า** · ตัวกรองขยับ = ล้างที่เลือก (ทรงเดียวกับ `/tax/registrations`) ·
  ป้ายจำนวนเป็น `เลือก x/y ใบ` · ใบในชุดเรียงตามที่ตารางเรียงอยู่
- เพดาน **50 ใบต่อครั้ง** (`SALES_ORDER_BUNDLE_MAX`) — รวมในหน่วยความจำของเบราว์เซอร์ · ปุ่มขึ้นเสมอ บอกเหตุตอนกด
  (ยังไม่ติ๊ก / เกินเพดาน)
