## กติกาตัวเลข

- **ใบที่นับ** = ตัวตัดสินเดียวกับแท็บสินค้าของหน้าลูกค้า (`countsAsOrdered` ใน `lib/master/customerHub.js`):
  `status = approved` · ยังมีผล (ไม่ถูก Rev. แทน/ไม่ยกเลิก) · ไม่ใช่ใบค่าสรรพสามิต · **รวมใบย้อนหลัง** (การสั่งจริงในอดีต)
  ⇒ ยอดสินค้า X บนหน้าลูกค้า = ยอดบนหน้าสินค้า X ทุกตัวอักษร
- มูลค่า = ผลรวม `lineTotal` (ก่อน VAT) · จำนวน = `lineUnitsTotal` (แพ็ค × จำนวน · ตัวกลางของ `linePacks.js`)
- ใบเสนอราคา: นับ **ฉบับล่าสุดของแต่ละสาย Rev.** ที่มองเห็น ยกเว้นใบค่าสรรพสามิต · Won = ฉบับล่าสุดที่ `status = accepted` ·
  ราคาล่าสุด = ราคา/หน่วยบนฉบับล่าสุดที่ใหม่สุด (ใบที่สินค้าเดียวกันมีหลายราคาข้ามไป) · แท็บซ่อนฉบับเก่าตั้งต้น (ปุ่มโชว์ ทรงเดียวกับหน้าลูกค้า)
- ใบค่าสรรพสามิต (`origin = excise`) ไม่ใช่การขายสินค้า — ไม่ขึ้นแท็บการขาย ไม่นับยอด

### S1 — รายละเอียด

- **ข้อมูล**: `lib/master/productHubData.js` `productSalesRelations(supabase, productId, user)` — บรรทัด QT/SO ที่ `productId` ตรง →
  ใบแม่ → กรองด้วยด่านเดียวกับหน้าลูกค้า (`canViewSalesPlanning` + `inSalesDocScope` ผ่านดีล/ดีลต้นทาง) · คืน `{ visible, quotations, orders }`
  ทุกใบติด `lines` ของสินค้านี้ · ⚠️ query พัง = throw (route ตอบ 500) ห้ามคืนลิสต์ว่าง
- **ตัวคำนวณ**: `lib/master/productHub.js` (pure) — `productSalesFacts` · `productOrderRows` · `productQuoteRows`
- **API**: `GET /api/products/[id]/relations` เพิ่มคีย์ `sales`
- **จอ**: หัวเต็มกว้าง (`SalesDetailOverview` นอก `DetailPageLayout`) · ตัวเลขบนหัว: ยอดสั่งซื้อสะสม · จำนวนที่สั่ง · ใบเสนอราคา (เฉพาะผู้เห็นการขาย) + ลูกค้าเจ้าของ ·
  รางขวา = `DocumentSummaryCard` "สรุปสินค้า" (หมวด · ปริมาตร · ราคา · ภาษี/หน่วย + สถานะรายเรื่องกดไปแท็บ · สถานะการใช้งาน) + การ์ดจัดการเดิม ·
  แท็บ "การขาย" = `HubListPanel` สองมุมมอง (ใบสั่งขาย / ใบเสนอราคา)
