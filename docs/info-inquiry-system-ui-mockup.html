สอบถามข้อมูล — ทุกขั้นตอนของ SA และ RD

หัวข้อคำร้องที่เบาที่สุดในระบบ: ไม่มีตารางรายการ ไม่มีราคา ไม่มีไฟล์บังคับ — ทั้งใบคือ "คำถามหนึ่งเรื่อง + เธรดถามตอบ" ใช้เมื่ออยากถามฝ่ายอื่นเรื่องที่ยังไม่มีหัวข้อเฉพาะ

ทุกจอในไฟล์นี้ตรงกับโค้ดที่ merge แล้วจริง (ม-83 · ม-84 · ม-87 · ม-92 มีผลครบ)

SA ฝ่ายขาย — ผู้ถาม RD ฝ่ายวิจัยฯ — ผู้ตอบ เส้นทางเดียวกันนี้ใช้กับทุกฝ่ายที่จะเปิดในอนาคต (PC · FN) — หัวข้อนี้ไม่ผูกฝ่าย

✦เส้นทางทั้งหมดในหน้าเดียว

SA ผู้ถาม

  1. เปิดคำร้อง เลือกฝ่าย RD · หัวข้อ "สอบถามข้อมูล"
  2. เลือกดีล (ลูกค้า/โครงการขึ้นเอง) · ตั้งเรื่อง · วันที่คาดหวัง · แนบไฟล์
  3. ส่ง — เลขที่ RQ ออก
  4. ตอบคำถามเพิ่มในเธรดเมื่อ RD ถามกลับ
  5. พอใจคำตอบ → ปิดเรื่อง

RD ผู้ตอบ

  1. เห็นใบในคิว → รับเรื่อง + วันกำหนดตอบ (บังคับ)
  2. ถามข้อมูลเพิ่ม / ตอบในเธรด · แนบไฟล์ได้
  3. ตอบครบ → กด "ตอบแล้ว" (ระบบประทับเวลาให้)

ระบบ

  1. ออกเลขที่ RQ · แจ้งเตือนฝ่ายปลายทาง + คนที่ถูกกล่าวถึง
  2. เขียนทุกก้าวลงเธรดเดียว (ส่ง/รับ/ตอบ/ปิด)
  3. คิว RD ใช้วันกำหนดตอบชี้งานเลยกำหนด
ป้ายรางขั้นกลางเป็นคำเฉพาะสายแล้ว: หัวข้อไม่มีรายการ (สอบถามข้อมูล) ขึ้น "รอฝ่าย RD ตอบ" — ส่วนหัวข้อที่ฝ่ายส่งของจริง (พัฒนากลิ่น) ยังขึ้น "รอฝ่าย RD ส่งของ" ตามเดิม (มติผู้ใช้ 2026-08-09)
