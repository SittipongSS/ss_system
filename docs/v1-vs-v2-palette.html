สี v1 vs v2 — ต่างกันตรงไหน

ค่าดึงตรงจาก globals.css วันนี้ · แถวที่ไฮไลต์ = ค่าต่างกันจริง

ข้อสำคัญก่อนอื่น — v2 ไม่มีธีมสว่าง
คอมเมนต์ในโค้ดเขียนไว้เอง: "v2 มีโหมดเดียว (มืด) — ธีมสว่างเป็นการตัดสินใจค้างของ Phase 1 จึงทับทั้ง :root และ [data-theme="dark"]"
⇒ เปิด v2 แล้วสวิตช์ธีมสว่างไม่มีผล ได้พื้นมืดเสมอ · ถ้าคนส่วนใหญ่ใช้สว่าง นี่คือเหตุผลที่ "สี v2" ดูผิดตั้งแต่แรก — ไม่ใช่เรื่องเฉดสี แต่เป็นเพราะธีมที่เคยใช้หายไปทั้งธีม

3 · v2 เปลี่ยนอะไรนอกจากสี

พื้นผิวกระจก (alpha + blur) → ทึบ 100%
เงาการ์ดมีเงานุ่ม → เหลือเฉพาะแผงลอย (dropdown/ปฏิทิน)
gradientพื้นหลังมีแสงโคม 4 มุม → ไม่มี
ตัวแบ่งชั้นเงา+พื้นต่างระดับ → เส้น 1px
แถบบนสุดnavy แบรนด์ → เกือบดำ (มติ 2026-08-08 "กดดำเลยก็ได้")
ความหนาแน่นอัดแถว/ระยะห่างให้แน่นขึ้น (ยังคงไว้ได้แม้เปลี่ยนสีกลับ)

4 · ทางเลือก

กทำธีมสว่างให้ v2 — เก็บโครง/ความหนาแน่นของ v2 ไว้ แต่ใช้จานสีครีมอุ่นของ v1 บนธีมสว่าง และให้สวิตช์ธีมกลับมาทำงาน (งานที่ Phase 1 ค้างไว้)
ขv2 ใช้สี v1 ทั้งสองธีม — คงเฉพาะภาษา flat/หนาแน่น เปลี่ยนจานสีกลับเป็นของเดิมทั้งชุด
คเลิก v2 — ปิดสวิตช์ถาวร ยกเลิก Phase 4 กลับไปใช้ v1 ล้วน
งแก้เฉพาะจุดที่ขัดตา — บอกมาเป็นข้อ (เช่น แถบบนดำเกินไป · พื้นมืดเกินไป · อยากได้การ์ดกระจกคืน)
