หน้าตาแต่ละสถานะ

🔴 ความหมายของหมุด — ✓ เขียว = ขั้นนั้นเรียบร้อยแล้ว · ตัวเลขส้ม = กำลังอยู่ขั้นนั้น รอดำเนินการ · ใบที่จบครบทุกขั้นจึงเป็น ✓ ทั้งราง ไม่มีเลขค้าง

กติกาที่ฝังไว้ในโค้ดแล้ว

ตีกลับไม่ถอน Actual

ยอดอยู่บนแกน status ที่บัญชีไม่แตะ · โมดัลตีกลับจึงไม่พูดถึงยอดเลย ไม่งั้นบัญชีเข้าใจว่ากดแล้วยอดขายหลุด

ตอนถูกตีกลับ บัญชีอนุมัติทับไม่ได้

ต้องให้ AE Sup กด “ส่งให้บัญชีตรวจใหม่” ก่อน ไม่งั้นการตีกลับไม่มีความหมาย

บัญชีกด “ส่งตรวจใหม่” เองไม่ได้

ไม่งั้นตีกลับแล้วส่งเข้าคิวตัวเองครบวง = ด่านหายไป · มีเทสต์ล็อกไว้

ฝ่ายขายตรวจแทนบัญชีไม่ได้

รวมถึง ae_supervisor ที่เพิ่งอนุมัติใบนี้เอง — ถ้าตรวจซ้ำได้ก็ไม่มีด่านที่สอง

ใบเก่าไม่โผล่ขั้นนี้เลย

ใบที่อนุมัติก่อน mig 0250 ได้ NULL = “ออกก่อนมีขั้นนี้” ไม่ใช่ “รอบัญชี” · ตั้ง pending ย้อนหลังเมื่อไร บัญชีเปิดมาเจอคิวค้างทั้งกอง

ไม่แทรกเป็นสถานะกลางทาง

status='approved' เป็นตัวปลดล็อก 12 จุด (Actual · กลิ่น · ผลิต · ภาษี · handoff · ลายน้ำ · งวดชำระ) แทรกกลางเมื่อไรหยุดรอบัญชีหมด
