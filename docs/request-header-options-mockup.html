คำร้อง · หัวใบ (หน้ารายละเอียด)

แบบที่เลือก — คนอยู่บนหัว เวลาอยู่ในแถบ

สองฝั่งของใบอยู่ติดกันบนหัว — ชิปซ้ายคือผู้ยื่น ชิปขวาคือผู้รับเรื่องฝ่ายปลายทาง · ลูกค้า ต่อท้ายหัวข้อเรื่องเป็นประโยคเดียว · แถบข้างล่างเหลือแต่เรื่องเวลา — ชั้นบน "เดินมาถึงไหน" ชั้นล่าง "สัญญาว่าเมื่อไร"

RD กำหนดส่งยังไม่ระบุระบุตอนกดรับเรื่อง
  • ชิปคู่อ่านเป็นเส้นทางเดียว — ผู้ยื่น → ผู้รับเรื่อง · ฝั่งขวายังว่างก็ขึ้นชิปขอบประว่า "ยังไม่มีใครรับเรื่อง" ไม่ใช่หายไปเฉย ๆ
  • ชิปม่วง = ใบของเพื่อนร่วมทีม · ใบของตัวเองใช้ชิปเขียวอมฟ้าเขียนว่า "ใบของฉัน" (ดูตัวอย่างที่ 2)
  • ลูกค้าอ่านต่อจากหัวข้อเรื่องได้เลย — "ขอ Mockup … ให้สปาฟินเเลนด์ AR-899"
  • ชั้นล่างมีสองช่องคู่กันเสมอ ⇒ เห็นทันทีว่าฝ่ายยังไม่รับปากวันทั้งที่ผู้ขอตั้งวันไว้แล้ว
