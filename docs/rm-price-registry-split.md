# ราคาวัตถุดิบอยู่ที่ทะเบียนกลิ่น/สูตร — ทะเบียนวัสดุเหลือบรรจุภัณฑ์

> สถานะ: **เสร็จสมบูรณ์** · ตรวจกับโค้ดเมื่อ 2026-08-10 · มติ + งานที่ส่งในรอบเดียวกัน

## มติ (ผู้ใช้ 2026-08-10)

1. **`/database/materials` เหลือบรรจุภัณฑ์ (PM) อย่างเดียว** — ทะเบียนนี้จะไปผูกกับ
   โมดูลจัดซื้อในเฟสหน้า
2. **ราคา RM ย้ายไปจัดการที่ทะเบียนของตัวเอง** — ราคา F (หัวน้ำหอม ฿/กก.) อยู่บน
   ทะเบียนกลิ่น · ราคา FB (เนื้อสาร ฿/กก.) อยู่บนทะเบียนสูตร
3. โมเดลข้อมูลของ Product Spec ที่คุยไว้: 1 กลิ่น : N สูตร · 1 สูตร : 1 FG
   (ขา สูตร↔FG ยังไม่ทำในรอบนี้ — ดู "งานต่อ" ท้ายไฟล์)

## หลักการที่ **ไม่** เปลี่ยน

- **ที่เก็บราคายังเป็น `material_prices` ที่เดียว** (มติ PR #1117): ทะเบียนกลิ่น/สูตร
  *แสดงและจัดการ* ราคา แต่ไม่เก็บสำเนาของตัวเอง — สองแหล่งจะขัดกันเองแล้วไม่มีใคร
  ตอบได้ว่าใบขอราคาผลิตควรเชื่ออันไหน
- rev เป็น immutable + ชั้นจำนวน (mig 0157) · F/FB ไม่มีชั้นจำนวน ราคาเดียวต่อ กก.
  (มติ 2026-08-03) · อายุราคา 90 วัน
- ใบขอราคาผลิต (`fill-prices`) อ่านจาก `material_prices` เหมือนเดิม ไม่ต้องแก้

## สิ่งที่ส่งในรอบนี้

| ชิ้น | ไฟล์ |
|---|---|
| ทางเข้าราคากลาง — ก้อนเดียวใช้ทั้งสายคำร้องและปุ่มบนทะเบียน | `lib/materialPricesAdmin.js` (`priceRegistryEntry`) — ยกมาจาก `price/route.js` เดิม |
| API ใส่ราคาบนทะเบียน (สิทธิ์ RD = `canQuoteMaterial`) | `api/master/scents/[id]/price` · `api/master/formulas/[id]/price` · factory ที่ `lib/master/registryPriceRoute.js` |
| ปุ่ม "ใส่ราคา F / ออกราคา F ใหม่" บนหน้ารายละเอียด | `database/scents/[id]` · `database/formulas/[id]` + `components/database/RegistryPriceModal.js` (โมดัลเดียวสองทะเบียน) |
| ทะเบียนวัสดุเหลือ PM | หน้า `database/materials` กรอง PM · `MaterialForm` ตัดช่องชนิด/สูตร · `MaterialRegistryPanel` ตัดตัวกรอง+คอลัมน์ชนิด · POST `/api/sa/materials` ตีกลับ kind ≠ PM |
| เทสต์ล็อกกติกา | `lib/master/registryPriceRoute.test.mjs` — ตัวตนวัสดุเดิมต่อ rev ไม่เกิดตัวใหม่ · pointer ประทับครั้งเดียว · สิทธิ์/สถานะ/ราคา |

ที่มาของช่องว่างที่ปิด: ทางใส่ราคา RM เดิมมีทางเดียวคือขั้นราคาบนคำร้องสายพัฒนา —
กลิ่นที่ "เพิ่มเอง" เข้าทะเบียน (ของจริง ณ วันเขียน: ทั้ง 43 ตัว) จึงไม่มีทางมีราคาเลย
และฟอร์มเพิ่มวัสดุ RM แบบมือก็ประทับ `scentId` ไม่ได้ (ราคาที่กรอกเลยไม่ขึ้นบนทะเบียน)

## งานต่อ (ยังไม่เริ่ม)

- **Product Spec ขา สูตร↔FG**: ผูก 6 สูตรจริงเข้า FG · จัดระเบียบสินค้าค้าง 12 แถว
  (มีแถว `formulaDate` ปี 2202 รอผู้ใช้แก้) · derive กลิ่นบนสินค้าจากสูตร · บังคับ
  1 สูตร : 1 FG (ตอนนี้ products.formulaId = 0 ทุกแถว ใส่ unique ได้ไม่มีอะไรชน)
  · PM lines ต่อ FG
- **โมดูลจัดซื้อ**: ต่อทะเบียนวัสดุ (PM) เข้าสายสั่งซื้อ — ตอนนั้นค่อยตัดสินเรื่อง
  ผู้ขาย/MOQ/lead time เป็นโครงสร้างจริงแทน `supplierNote`
- แถว RM เดิมใน `material_prices` อยู่ครบและยังเป็นแหล่งราคา — **ห้ามลบ**
  (ใบขอราคาผลิต/คำร้องเก่าอ้างอยู่) แค่ไม่จัดการจากหน้าทะเบียนวัสดุแล้ว
