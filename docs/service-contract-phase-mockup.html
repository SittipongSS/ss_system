ทุกฝ่าย · /sales-planning/sales-orders/[id] — รื้อจากหน้ายาวการ์ดต่อกัน เป็น หัวคงที่ + แถบสถานะเส้น + 5 แท็บ (เส้นบริการ)

แท็บแบ่งตามเรื่อง ไม่ใช่ตามฝ่าย — ทุกฝ่ายเห็นแท็บชุดเดียวกัน สิทธิ์คุมที่ปุ่มในแท็บ (ล็อกดีกว่าซ่อน) · หัวใบ + แถบสถานะเส้นเห็นตลอดไม่ว่าอยู่แท็บไหน = "มองทางเดียวกัน" ของจริง · ชุดแท็บงอกตามเกณฑ์ใบ: ใบมีรอบบริการได้แท็บ "งานบริการ" · ใบสายอื่นแท็บนี้หายไป (จุดขยายของต้นแบบ: สายผลิตใส่แท็บ "งานผลิต" แทน) · ลิงก์ข้ามโมดูลชี้ตรงแท็บ (?tab=payment ฯลฯ): กระดิ่ง/คิว FN เข้าแท็บการชำระ · TS เข้าแท็บงานบริการ

  • +1 ภาพรวม — ยอด · รายการสินค้า(+รอบ) · ข้อมูลบนเอกสาร · เอกสารยืนยัน · การ์ดอ้างอิง ดีล/QT/โครงการ
  • +2 สัญญา — การ์ดสัญญา/เอกสารภายนอก + สถานะอนุมัติ + Rev./บันทึกเพิ่มเติม
  • +3 การชำระ — แผงงวดเดิม + ช่วงครอบ + จ่ายถึง (SA แจ้ง · FN รับรอง ที่เดียวกัน)
  • +4 งานบริการ — จัดสรร/รอบ/นัด + ลิงก์กระโดด (เฉพาะใบมีรอบ)
  • +5 ประวัติ — audit trail + ฉบับแก้ไข
