# คู่มือพนักงานเข้า-ออก กับ Target / Forecast / Actual

อัปเดต 2026-11-27 · คู่กับฟีเจอร์ "โอนงาน" ในหน้า ตั้งค่า → ผู้ใช้งาน (ปุ่ม ⇄) และ "ส่งต่องาน" ในหน้าดีล/ลูกค้า

**หลักจำ:** TG (เป้า) ผูกกับ "คน+เดือน" ในหน้าวางเป้า · FC (คาดการณ์) ติดไปกับ*ดีลที่เปิดอยู่* ·
AT (ยอดจริง) ติดกับ*ดีลที่ปิด Won แล้ว* → FC โยกด้วยการโอนดีล, TG โยกด้วยการแก้เป้า, **AT ไม่โยกเลย**

**นโยบาย:** เดือนที่ผ่านมาแล้วไม่โยกอะไรทั้งสิ้น — ประวัติคงใต้ชื่อเดิมจนจบปี
ปีใหม่รีเซ็ตด้วยรายชื่อคนที่ active เท่านั้น (ระบบจัดการให้เอง)

---

## 🟢 พนักงานเข้า

1. **สร้างบัญชี** — ตั้งค่า → ผู้ใช้งาน → เพิ่มผู้ใช้ (กำหนดบทบาท + ทีม)
2. **ใส่เป้า** — หน้าวางเป้า → กรอกเป้ารายเดือน**ตั้งแต่เดือนที่เริ่มงาน**
   (เดือนก่อนหน้าปล่อยว่าง — % รายปีจะได้ไม่โดนหารด้วยเดือนที่ยังไม่ได้ทำงาน)
3. **FC ไม่ต้องทำอะไร** — เกิดเองเมื่อสร้าง/รับโอนดีล
4. **รับพอร์ตต่อจากคนเก่า** — ใช้ปุ่ม "โอนงาน" (ดูฝั่งออก)

## 🔴 พนักงานออก

1. **ระงับบัญชีทันที** — ตั้งค่า → ผู้ใช้งาน → ปุ่มแม่กุญแจ (ปิดบัญชี **ห้ามลบ**)
   → เข้าระบบไม่ได้ทันที, หายจาก dropdown ทุกจุด, ข้อมูล/ประวัติอยู่ครบ
2. **กดปุ่ม "โอนงาน" (⇄)** ที่แถวของคนออก → เปิดหน้า **โอนงาน** (อัปเดต 27/11/2026 · เดิมเป็นโมดัลที่ยกทุกอย่างให้คนเดียว)
   หน้านี้โชว์งานที่ยังค้างชื่อเขาเป็นรายการ **เลือกทีม + คนรับทีละรายการ** (ติ๊กหลายแถวแล้วส่งให้คนเดียวได้) โอนแล้วรายการหายไปจนเหลือ 0:
   - **ดีลที่ยังเปิด** — เจ้าของ + ทีม ย้ายไปคนรับ → FC ย้ายตามทันที · เลือก AC / AE Supervisor ใหม่ได้ทุกแถว
   - **ดีล Won ที่งานยังไม่จบ** — ยังไม่ออก SO · SO ยังไม่อนุมัติ · สัญญายังไม่จบ · ยังมีงวดเงินที่บัญชียังไม่ยืนยัน
     → คนรับตามงานต่อ · **ยอดขาย (AT) ของ SO ที่อนุมัติแล้วยังนับให้คนเดิม**
   - **ของที่ย้ายตามดีล** — SO ที่ยังไม่อนุมัติ (ผู้สร้าง) · สัญญาที่ยังไม่จบ (ผู้ดูแล + ผู้สร้าง) · ชื่อผู้เสนอราคาบนใบเสนอราคาเปลี่ยนตามเอง
   - **ลีดที่ยังเปิด** — ผู้รับผิดชอบย้ายไปคนรับ
   - **เป้าตั้งแต่เดือนถัดไป** — แบ่งให้หลายคนได้: กรอกยอดรายเดือนต่อคน (มีปุ่มเกลี่ยเท่ากัน) ผลรวมต้องเท่าเป้าเดิมพอดี ต้นทางเหลือ 0
   - **ทีมของงานที่โอน = ทีมที่เลือกในแถว** (ตั้งต้นเป็นทีมเดิมของงาน) — คนรับต้องอยู่ทีมนั้น
   - **ดีล Won ที่งานจบแล้ว · Lost · เป้าเดือนเก่า: ไม่ถูกแตะ** — คนรับได้กระดิ่งหนึ่งครั้ง · ทุกรายการมี audit
   - ดีลของใบสั่งขายย้อนหลัง ย้ายเจ้าของที่ฟอร์มแก้ไขดีลทีละใบ (หน้าโอนงานบอกจำนวนที่ยังค้าง)
3. **ส่งต่องานบางดีล/บางลูกค้า ระหว่างที่คนยังทำงานอยู่** — AE Supervisor/Admin กด "ส่งต่องาน" ใน Control Panel
   (รางขวา) ของหน้าดีล หรือหน้าลูกค้า · ของที่ย้ายตามเหมือนข้อ 2 · คนเดิมหยุดได้กระดิ่งเธรดของดีลที่ส่งต่อไป

**เอกสาร Google ที่เขาเคยเปิด** — ไม่ต้องทำอะไรถ้าปิดบัญชีอีเมลบริษัทตามปกติ สิทธิ์บนไฟล์
ผูกกับ*อีเมล* พอบัญชีถูกปิดก็ล็อกอินเป็นอีเมลนั้นไม่ได้ สิทธิ์ที่ค้างเป็นบรรทัดตาย
ถ้าอยากล้างให้สะอาดจริง ๆ กดปุ่มโล่ที่แถวของเขาได้ (ดูหัวข้อ "ย้ายทีม")

### เดือนคาบเกี่ยว (ออกกลางเดือน)
AT ที่ปิดไปแล้วอยู่กับคนเก่า / FC ดีลเปิดย้ายไปคนใหม่ → % ต่อเป้าเดือนนั้นดูแบ่งกันสองคน
**แนะนำ: ปล่อยไว้แล้ววัดเดือนนั้นที่ระดับทีมแทน** (หน้าโอนงานจึงโยกเป้าตั้งแต่ "เดือนถัดไป" เท่านั้น ·
ถ้าต้องการโยกเดือนปัจจุบัน แก้ที่หน้าวางเป้า)

## 🔄 ย้ายทีม

1. แก้ทีมที่บัญชีผู้ใช้ (หน้า ผู้ใช้งาน → แก้ไข)
2. ดีลที่ยังเปิด: แก้ทีมของดีลให้ตามไป (ใช้ปุ่มโอนงานโอนให้ "ตัวเอง" ไม่ได้ — แก้ทีละดีล
   หรือแจ้งผู้ดูแลระบบ) — ดีลเดือนเก่ารายงานใต้ทีมเดิม ถูกต้องแล้ว
3. เป้าเดือนอนาคต: ย้ายจากตารางทีมเก่าไปทีมใหม่ในหน้าวางเป้า
4. **กดปุ่มโล่ (ถอนสิทธิ์เอกสารร่วม)** ที่แถวของคนย้าย — นี่คือจุดที่ต่างจากคนลาออก:
   บัญชีเขายังใช้ได้ ระบบตัดสิทธิ์เห็นดีลของทีมเก่าทันทีก็จริง แต่เอกสาร Google ที่เคย
   เปิดยังเปิดได้อยู่ผ่านลิงก์เดิม/"แชร์กับฉัน" จนกว่าจะกดถอน
   → ถอนแล้วถ้าเขายังมีสิทธิ์เห็นเอกสารใบไหนอยู่ ระบบให้สิทธิ์คืนเองตอนเขาเปิดจากในระบบ

## สิ่งที่ระบบจัดการให้อัตโนมัติ (ไม่ต้องทำมือ)

- คนถูกระงับหายจาก dropdown มอบหมายงาน + wizard แจกเป้าปีใหม่ (PR #401)
- หน้าวางเป้า: เป้าค้างของคนออกโชว์เป็นแถว "ออกจากระบบแล้ว" (เกลี่ยออกได้) และหายเองเมื่อยอดเป็น 0/ขึ้นปีใหม่
- หน้า KPI ดีล: แถวรายบุคคลของคนออกติดป้าย "ออกจากระบบแล้ว" (PR #402) และหายเองปีถัดไป
- เอกสารโครงการเก่ายังเติมเบอร์/อีเมลของ AE ที่ออกไปแล้วได้
